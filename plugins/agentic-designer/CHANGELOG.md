# Changelog

## 1.1.0 (2026-10-13): runs for real
- **Session preflight** (works without Node.js): shows the loaded version, warns if Node.js is missing, and creates the workspace (lessons, state, taste, DS gaps, plans) automatically.
- **Hard steps:** every plan states its lane; Standard, Explore and Flow work waits for the Fresh Eyes verdict file before the full build; every summary ends with the gate result and the number of lessons logged.
- **Precedence rule** when reviewers disagree (accessibility, regulation, brief, locked content, domain, taste, style), a note on supported surfaces (Claude Code and Cowork), long-task notices, and a DS gaps log.
- **Motion:** budget per alternative, mandatory seam check between screens, splash rules (timing, when it plays, Android 12+ sizing), a fixed handoff package, and a dev checklist for platform code.
- **kiki-lint v5:** crypto asset names are not currency violations; text over gradients is checked against the worst stop as an advisory.
- Cleanup: one lane list everywhere, clearer lint config, finance and crypto packs ask to verify regulatory claims before use.

## 1.0.0 (2026-10-13): first public release
- **Jarvis**, a god-level product designer agent that plans in ≤ 15 lines, builds real screens in Figma with your design system,
  polishes them from screenshots, and checks them with a lint script, for every industry, style, and device (incl. foldables).
- **Fresh Eyes** critic (sees only screenshots, taste, and rubric) with a cheap pixel-diff mode.
- **Pandu** for prototypes (HTML with a device viewer, or Figma) and motion (Figma, Lottie JSON, or dev spec).
- **Desi** for design systems: `/add-ds` stores your DS once; `/new-brand` and `/optimize-brand` manage brand modes safely.
- **Pram** (PRDs, research), **Wulan** (copy, localization), **Dev** (engineering advice), **Sari** (nightly learning).
- Screen naming `flow.context.state[.variant][.device]`, `/rename-screens`, lanes for exploration, flows, and DS maintenance,
  checkpoints and `/resume`, `/init`, `/doctor`, a live 3D office, a 121-check test suite.
