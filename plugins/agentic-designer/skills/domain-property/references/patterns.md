# Property patterns (deep)
- Search: location-first (area, station, landmark), filters (price, LT/LB, KT/KM, certificate, furnished), saved searches with alerts.
- Results: map+list sync (selected pin ↔ card), price per m² toggle, sort by newest/price/nearest.
- Listing detail: gallery with count, video/virtual tour badge, price + estimated installment, key specs grid, facilities, location with commute times, agent/developer card with response time, similar listings, report listing.
- Developer project page: unit types with floor plans, availability, price lists, promo periods, progress updates.
- KPR: simulator (DP %, tenor, fixed/floating period, rate), bank offers comparison, eligibility pre-check (income range), document checklist.
- Contact: chat with prefilled question, call, schedule visit (date/time slots, confirmation, reminder).
- Rental/kos: availability calendar, deposit/advance rules, house rules, bills included, booking & payment.
- States: sold/rented, price changed, listing expired, no results for filters (suggest widening).
