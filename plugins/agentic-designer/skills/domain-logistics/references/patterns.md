# Logistics patterns (deep)
- Track: resi input/scan, current status + ETA hero, timeline (time, location, event), courier contact, proof of delivery (photo, receiver name, signature).
- Send: sender/receiver (address book), package details (size presets, weight, item type with prohibited-items check), service comparison (price, ETA), insurance, pickup vs drop-off (nearest points), payment, booking code/label.
- Business: bulk upload shipments (CSV) with validation errors, label printing, pickup scheduling, COD reconciliation, invoices.
- Driver app: route list ordered, navigation handoff, arrive → deliver/fail with reason picker, photo POD, cash collection, offline queue, large targets (≥ 56) and high contrast.
- Ops dashboard: shipments table with SLA flags, map view, exceptions queue (failed attempts, address issues, delays) with bulk actions.
