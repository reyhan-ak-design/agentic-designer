| | |
|---|---|
| Owner | <PM> · Status: Draft / In review / Approved · Version <n> · <date> |
| Stakeholders | PO, Design, Eng (iOS/Android/Web/BE), QA, Legal/Compliance (if relevant) |
| Links | Research brief · Figma · Tickets |

## 1. Summary
Two to four sentences: what we are building, for whom, and why now.

## 2. Problem & context
- Problem statement (user + business), evidence (data, research findings, quotes), current state.

## 3. Goals & non-goals
- Goals (measurable) · Non-goals (explicitly out) · Later (future phases)

## 4. Success metrics
| Metric | Baseline | Target | Timeframe | Source |
Primary metric, guardrail metrics (what must not get worse).

## 5. Users & jobs
- Personas/segments with context · Jobs-to-be-done ("When …, I want to …, so I can …")

## 6. Scope
In scope (MVP) · Out of scope · Assumptions · Dependencies

## 7. User flows
Numbered happy path + key alternate/error paths (text; link Figma when designs exist).

## 7b. Screens & API mapping (feeds the prototype)
| # | Screen | Purpose | Endpoint(s) | Key fields shown | States (loading/empty/error codes) |
|---|---|---|---|---|---|

## 8. User stories & acceptance criteria
| ID | As a … I want … so that … | Priority (Must/Should/Could) |
Each story:
- **AC1** Given … When … Then …
- **AC2** …

## 9. Functional requirements
| ID | Requirement | Rules / validation | Priority |
Include business rules, limits, permissions/roles, calculations, notifications.

## 10. States & edge cases
Loading, empty, errors (per cause), offline/timeout, partial data, permissions, limits, long content, zero/max values.

## 11. Non-functional requirements
Performance, security & privacy (PDP), accessibility (WCAG AA), reliability, localization, audit/logging, compliance.

| Event | Trigger | Properties | Purpose |

## 13. Content & copy
Key copy needs, tone, legal copy owners (`[copy: legal]`).

## 14. Risks & mitigations
| Risk | Likelihood | Impact | Mitigation |

## 15. Release plan
Phases, feature flags, rollout %, migration, support/ops readiness.

| Question | Owner | Due |

Research summary, competitor notes, glossary.
