# Travel & hospitality patterns (deep)
- Search: product tabs (pesawat, kereta, hotel, aktivitas), origin/destination with recent routes and swap, date picker with price hints, passengers/rooms stepper.
- Results: sort (cheapest, earliest, fastest), filters (stops, time windows, airline, baggage, refundable), price calendar strip, flexible dates.
- Flight/train detail: timeline (depart → stops → arrive, durations, timezones), baggage, meal, fare rules (refund/reschedule fees), seat map option.
- Hotel: gallery, rating/reviews, location map, room types (bed, size, breakfast, refundable), price per night + total with taxes, policies (check-in, cancellation).
- Booking: traveler details (saved travelers, ID/passport per rule), contact, add-ons, review, pay; hold/expiry timer where inventory is held.
- Trips: upcoming/past, e-ticket/voucher (booking code large, QR), check-in, reschedule/refund flows with fee preview, travel alerts (delay, gate change).
