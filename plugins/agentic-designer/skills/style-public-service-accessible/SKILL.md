# Style Pack — Public-service Accessible

## Personality
Plain, dependable, for everyone. Function beats flourish.

## Typography
- System-friendly, legible sans (Plus Jakarta Sans, Source Sans 3, Noto Sans for multi-script).
- Body 16–18; clear headings; no decorative fonts.

## Color
- Institution color at 500 for actions; high-contrast text (≥ 7:1 body target).
- Semantic colors with icon + text always.

## Density & spacing
One question per screen for complex forms; clear step indicators.

## Shape & elevation
Visible input borders (1.5–2); radius small–medium (6–8); no decorative shadows.

## Iconography & imagery
Labeled icons; minimal imagery (bandwidth); vector over photo.

## Motion
Almost none; respect reduced motion; no auto carousels.

## Visual recipes (component treatments)
- **Page:** plain white, institution color only for actions and headers.
- **Forms:** one question per page for complex flows, big inputs (56), visible labels, hints above.
- **Buttons:** full-width primary 56, secondary as link-style text.
- **Content:** plain-language headings, short paragraphs, numbered steps.
- **Low-bandwidth:** no decorative images on task screens; icons with labels.

## Density tiers (applies `layout-and-spacing`)
Comfortable-plus. One question per screen for complex forms. T1 16 · T2 24–32 · T3 40; targets ≥ 48.

## Don'ts
- STY-PS-01 [J][Blocker] — No heavy imagery on core task screens (bandwidth).
- STY-PS-02 [J][Blocker] — No contrast below AA anywhere; aim AAA for body.
- STY-PS-03 [J][Major] — No jargon-first copy; plain language first, legal reference second.
- STY-PS-04 [J][Major] — No hidden navigation (hamburger-only) for primary services.

## Taste kit (use it — this is what makes screens memorable)
**Typography.** DS sans, body 16–18, headings plain and short; one question per page in complex flows; numbered steps.

**Color proportion.** White background · institution color for headers and primary actions only · semantic colors with icons and text; contrast AA minimum, AAA for body where possible.

**Hero compositions (pick one per screen, adapt with the DS):**
1. **Service start page:** what you get · who can apply · what you need · start button.
2. **Status tracker:** clear timeline with the current step emphasized and the next action.
3. **Plain dashboard:** 3–5 service tiles with labels, search first.

**Signature moves (use exactly one per screen):**
- Big clear start button with the time estimate ("± 10 menit").
- Plain-language headings that answer a question.
- Confirmation panel with reference number in large type.

**Imagery / art direction.** Real citizens and places of the country, inclusive, candid; simple line illustrations for concepts; no decorative stock. Sources and placement: `visual-assets`.

**Real products to study (visual moves only, never copy):**
- GOV.UK — https://www.gov.uk
- Singpass — https://www.singpass.gov.sg
- U.S. Web Design System — https://designsystem.digital.gov
- SATUSEHAT Mobile — https://satusehat.kemkes.go.id
- NHS — https://www.nhs.uk

**Avoid.** Jargon, agency names as navigation, carousels, decorative images on task pages, time-outs without warning.

**Explore lane — the BOLD direction.** A warm illustrated welcome for the service start with one big action; task pages stay plain.
