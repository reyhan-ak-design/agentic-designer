# F&B patterns (deep)
- Outlet selection first (nearest/open now, pickup vs delivery vs dine-in), outlet status (busy, closing soon).
- Menu: sticky category tabs, item cards with photo, price, tags (only real), sold-out state; search; favorites/reorder.
- Customization sheet: required choices first (size), optional add-ons with price delta, sugar/ice levels, notes, quantity; running price in CTA.
- Cart: items with edit, outlet & order type, pickup time (ASAP/scheduled), promos/vouchers, loyalty points, tax/service, total.
- Order tracking: accepted → preparing → ready (pickup code large) / on the way (driver), ETA; call outlet.
- QR table order: table confirmed, shared cart for group, pay per person or together, call waiter.
- Loyalty: stamps/points, free item progress, birthday reward.
- Kitchen display (staff): order tickets by time, item modifiers highlighted, bump/complete, delay alerts.
