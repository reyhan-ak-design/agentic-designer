# Style Pack — Bold Editorial

## Personality
Loud where it matters, disciplined everywhere else. Typography is the hero.

## Typography
- Big display type (condensed or heavy grotesque, e.g. Archivo, Anton for display; neutral sans for body).
- Strong scale jumps; tight leading on display; generous body readability.

## Color
- High contrast: black/white base with one saturated brand color used in large blocks.
- Color blocks define sections; still one accent per screen.

## Density & spacing
Asymmetric layouts allowed; strong grid; big type with ample space around.

## Shape & elevation
Sharp or small radius (0–8); flat surfaces; no shadows.

## Iconography & imagery
Bold icons (2px or filled). Dramatic cropped photography.

## Motion
Snappy (150–250ms); marquee/scroll effects only on marketing surfaces.

## Visual recipes (component treatments)
- **Hero:** oversized display type with one saturated color block; tight leading.
- **Layout:** asymmetric, strong grid, big whitespace around type.
- **Imagery:** dramatic crops, full-bleed.
- **Core flows:** calm down to standard UI (forms/checkout stay minimal).
- **Buttons:** sharp or small radius, bold labels.

## Density tiers (applies `layout-and-spacing`)
Contrast in scale, not in crowding. T2 24–32 · T3 48+ around big type; core flows revert to standard density.

## Don'ts
- STY-BE-01 [J][Blocker] — No display fonts in form fields, numbers, or body text.
- STY-BE-02 [J][Major] — No more than one saturated brand color block per viewport.
- STY-BE-03 [J][Major] — No low-contrast text on color blocks.
- STY-BE-04 [J][Major] — Core flows (checkout, forms) calm down to standard UI.

## Suggested Brand Settings (for Desi)
| Group | Suggestion |
|---|---|
| font-family display/heading | Heavy/condensed display |
| font-family body/button | Neutral sans |
| font-weight display/h1 | ExtraBold–Black |
| radius | 0–8 |
| height button large/medium | 56 / 48 |

## Taste kit (use it — this is what makes screens memorable)
**Typography.** Oversized display (56–80 on marketing, 40–56 in-app heroes) with tight leading (1.0–1.1); strong weight contrast with body; asymmetric alignment.

**Color proportion.** Commit to 1–2 saturated colors in big blocks + black/white; accent is the block itself.

**Hero compositions (pick one per screen, adapt with the DS):**
1. **Poster hero:** giant headline over a color block, image cropped hard to one side.
2. **Big number story:** one huge statistic with a short caption (Wrapped-style).
3. **Stacked sections:** full-width alternating color bands with bold headings.

**Signature moves (use exactly one per screen):**
- Type as image: a word or number cropped by the frame edge.
- Hard color blocking with no gradients.
- Dramatic photo crops (faces or objects cut boldly).

**Imagery / art direction.** High-contrast photography, duotone treatments in brand colors, dramatic crops; strong single subject. Sources and placement: `visual-assets`.

**Real products to study (visual moves only, never copy):**
- The Pudding — https://pudding.cool
- Nike — https://www.nike.com
- Spotify Wrapped — https://www.spotify.com
- Bloomberg Businessweek — https://www.bloomberg.com/businessweek
- Pentagram — https://www.pentagram.com

**Avoid.** Editorial styling on dense forms/checkout (keep those calm), tiny body text, too many colors, centered everything.

**Explore lane — the BOLD direction.** Full-bleed type crop across the whole screen with one action — then calm UI below the fold.
