# E-commerce & marketplace patterns (deep)
- Home: search bar prominent, categories, personalized rails; promos limited and relevant (not a banner wall).
- Search: suggestions (recent, popular, category), results with filter chips (price, rating, location, shipping, official store), sort, applied-filter summary, no-results recovery.
- PDP: gallery (zoom, video), title, price block (final, strike-through, discount %, installment), variant selector (swatches/sizes with stock), quantity, shipping estimate to user location, seller card (rating, response time, official badge), vouchers available, description (collapsible), specs, reviews (with photos, filters), Q&A, similar products, sticky add-to-cart/buy now.
- Cart: grouped by seller, select all/per seller, stock/price-change warnings, seller vouchers, platform voucher, subtotal, checkout CTA.
- Checkout: address (saved, map pin), per-seller shipping choice with ETA and cost, insurance option, payment methods (VA, e-wallet, card, paylater, COD), voucher, cost breakdown, pay.
- Post-purchase: order status (Menunggu Pembayaran → Diproses → Dikirim → Selesai), tracking timeline with courier/resi, confirm receipt, review prompt, return/refund flow with reasons, photos, and status.
- Seller center: orders queue, product management (bulk edit), stock alerts, promotions, payouts.
