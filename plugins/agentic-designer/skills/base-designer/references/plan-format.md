# Plan format (text only — sent to Jarvis before any Figma work)

```
PLAN — <Screen> — <designer name>
Scope: <platform> · <domain pack> · <style pack>
Assumptions: <defaults you chose, one line each>

JOB: <user> needs to <job> so that <outcome>. Risk if wrong: <risk>.
PRIORITY GUIDE: <table from senior-design-craft/references/priority-guide.md — top 8 max>
EMPHASIS: hero = <x> · primary action = <label> · secondaries = <≤3>
MODE & TIERS: <Focused|Form|Operate> · T1 <n> · T2 <n> · T3 <n> · (tables: row <n>)
DIRECTION: feel = <3 words> · hero reference = <link> · signature moment = <one idea>
MOOD BOARD: <3 refs with what we take — see reference-research>
ART DIRECTION: <image sources, subjects, crop, treatment — see visual-assets>
REFERENCES (floor): <Mobbin pattern note, 3–6 lines>
KEYBOARD-UP PLAN: <what stays, what collapses> (if the screen has input)

ANATOMY (top → bottom)
1. <element> — <component from DS or DS GAP>
2. ...

STATES
- <state> — <what differs>

OPTIONS  (Explore: exactly 3 — SAFE · STRONG · BOLD, genuinely different directions, all built)
A. <name> — <layout strategy in one line> — trade-off: <one line>
B. ...
C. ...

SCORES (speed / hierarchy / DS fit / a11y / domain = total)
A: 3/3/2/3/3 = 14
B: 2/2/3/3/3 = 13

RECOMMENDED: A — <one sentence tied to the user goal>

BUILD SCOPE
- Standard: chosen option — default + ≤ 5 critical states
- Explore: A, B, C default states side by side (states only for the direction the Manager picks)

DS SUGGESTIONS (for Desi via Jarvis): <list or none>
BUILD SPEC: <path to build-spec.yaml — see references/build-spec.md>
QUESTIONS FOR DEV: <batched, or none>
```

Keep the whole plan under ~70 lines.
