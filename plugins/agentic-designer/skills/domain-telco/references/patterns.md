# Telco & utilities patterns (deep)
- Home: number/account switcher, quota rings with numbers and expiry, balance/pulsa, bill due (postpaid), top offers (max 1–2, personalized), quick buy last package.
- Package store: categories (data, combo, roaming, entertainment), filters by validity, card with quota breakdown (main/night/apps), price, validity, terms link; compare 2 packages.
- Purchase: package → payment (pulsa, e-wallet, VA, card) → confirmation → activation status (processing → active) with SMS fallback note.
- Usage: breakdown by type and by day, alerts at 80/100%, add-on suggestion.
- Postpaid/ISP: bill detail, autopay, payment history, service status/outage map, troubleshooting wizard, technician scheduling.
- Utilities: PLN token (meter number save, nominal, token display large + copy, history), PLN/PDAM bills (inquiry → pay).
- SIM/eSIM: registration with NIK consent, eSIM QR/activation steps, device compatibility check.
- States: package not available in area, activation delayed, insufficient pulsa, outage.
